# PyStand 踩坑实验计划（为将来 skill 化收集素材）

目标：在 `C:\WorkingProjects\python_projects\pystand-lab\` 手动走完 PyStand + 嵌入式 Python 的完整打包流程，把每个坑记录到 `NOTES.md`，作为将来 skill 的直接素材。本机无系统 Python（反而天然验证 standalone 效果）、无编译器，全程用官方预编译 exe + 免编译方案。

## 目录结构

```
pystand-lab/
├── NOTES.md                # 踩坑记录（边做边记：命令、报错、解法、skill 化要点）
├── demo/                   # 模拟用户的小项目
│   ├── main.py             # tkinter 窗口显示 sys.version + requests.__version__（一App覆盖三个验证点）
│   └── requirements.txt    # requests
├── tools/                  # 下载的 rcedit-x64.exe、get-pip.py
└── dist/DemoApp/           # 打包产物（PyStand 标准布局）
    ├── PyStand.exe         # v1.1.5 官方 64位 GUI 版（图标替换后改名 DemoApp.exe 验证改名机制）
    ├── PyStand.int         # 启动脚本（含 TCL_LIBRARY/TK_LIBRARY 处理）
    ├── runtime/            # python-3.12.5-embed-amd64 解压物
    ├── site-packages/      # pip 依赖（tkinter 纯 py 部分也放这里）
    └── runtime/tcl/        # tcl8.6/tk8.6 数据目录
```

## 执行步骤

1. **建骨架**：目录 + demo 项目 + NOTES.md
2. **下载**（curl，失败则记录并重试/换镜像）：
   - `python-3.12.5-embed-amd64.zip`（python.org，10.5MB）→ 解压到 `dist/DemoApp/runtime/`
   - PyStand `v1.1.5-exe.zip`（GitHub Releases）→ 取 64 位 GUI exe（CLI 版备用）
   - `get-pip.py`、`rcedit-x64.exe`（electron/rcedit Releases）
3. **pip 引导**（重点踩坑区）：
   - `runtime\python.exe get-pip.py`，观察隔离模式下的默认行为与警告
   - 编辑 `runtime\python312._pth`：取消 `import site` 注释 + 追加 `../site-packages`
   - `runtime\python.exe -m pip install -r requirements.txt`，确认依赖落到 `dist/DemoApp/site-packages/`
4. **tkinter 补齐**（复制源 = 本机 uv 管理的完整 Python 3.12，已验证文件齐全）：
   - `Lib\tkinter` → `site-packages\tkinter`（自动进 sys.path）
   - `DLLs\_tkinter.pyd / tcl86t.dll / tk86t.dll` → `runtime/`（runtime 在 sys.path 且 DLL 搜索目录已定向）
   - `tcl\`（tcl8.6/tk8.6）→ `runtime\tcl\`
   - `PyStand.int` 里设置 `TCL_LIBRARY`/`TK_LIBRARY` 环境变量
   - 备选：若 uv 版 `_tkinter.pyd` 与 3.12.5 embed 有 ABI 问题 → 下载 `python-3.12.5-amd64.exe` 静默安装到临时目录提取
5. **图标**：`uv run --with pillow python gen_icon.py` 生成多尺寸 .ico → `rcedit-x64.exe PyStand.exe --set-icon app.ico` → 改名 `DemoApp.exe` + 配 `_pystand_static.int` 验证改名机制
6. **启动验证**：
   - GUI 版：窗口出现、显示嵌入式 Python 版本号 + requests 版本、无控制台黑窗
   - CLI 版：跑 stdout print 验证（备用 exe）
   - 中文路径：复制整个 DemoApp 到中文路径跑一次
   - 本机无系统 Python，能跑通即证明 standalone 成立
7. **NOTES.md 收尾**：整理成「流程 + 坑 + 解法 + skill 化建议」结构

## 已验证的关键事实（计划依据）

- PyStand.exe 版本无关：加载 `runtime\python3.dll`（稳定 ABI 转发库），换版本只需换 runtime
- python.org 3.5+ 每个版本都有 embed 包，URL 模板固定
- `._pth` 隔离模式是 pip 流程的核心坑；PyStand 只把 HOME 下 `./lib/site-packages/runtime` 加进 sys.path
- tkinter 不可 pip 安装，须从同版本完整安装复制四件套（cpython#99566）
- PyStand 用 `-I -s -S` 启动，靠注入的初始化脚本 addsideDir；改名 exe 后需 `_pystand_static.int`
- 风险：改 exe 图标会提高杀软误报率（记录进 NOTES，不做实际杀软测试）
